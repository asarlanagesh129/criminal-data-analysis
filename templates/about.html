About the Project

Criminal Data Analysis and Crime Area Prediction Using Machine Learning

Project Overview

Criminal Data Analysis and Crime Area Prediction Using Machine Learning is a data analysis and machine learning project based on historical crime records.

The project analyzes crime patterns and develops a machine learning model to predict the community area associated with crime-related information.

Project Objective

The main objective of this project is to analyze historical crime data, identify meaningful patterns and develop a machine learning-based system for community area prediction.

The project also provides visual insights into crime trends based on year, month, hour, crime type and location.

Project Features

Crime Data Analysis

Analyze historical crime records and identify important crime patterns and trends.

Data Visualization

Display crime trends using charts for yearly, monthly, hourly and location-based analysis.

Machine Learning

Use a Random Forest model to learn patterns from historical crime data.

Crime Area Prediction

Predict a community area based on the information provided by the user.

Dataset

The project uses historical Chicago crime data. The dataset contains crime-related information including date, time, crime type, location, police district, beat, ward and geographical coordinates.

The data is processed and prepared before being used for analysis and machine learning.

Machine Learning Model

A Random Forest machine learning algorithm is used for community area prediction.

After training, the model is saved as a PKL file. The Flask application loads this trained model and uses it to generate predictions from user input.
