About the Project

This project focuses on criminal data analysis and crime area prediction using machine learning. Historical crime records are analyzed to identify patterns and useful relationships within the data.

A Random Forest machine learning model is used to predict the community area based on selected crime-related information such as date, time, district, beat, ward, geographical coordinates, and location description.

  • 🔍 Data Cleaning and Exploration

  • 🌐 Flask Web Application

Dataset & Details

The project uses historical crime records for data analysis, feature engineering and machine learning based community area prediction.

📊 Dataset Overview

The dataset contains historical crime-related information. The records include information about when and where crimes occurred, along with location and crime-related attributes.

The dataset is processed before training the machine learning model. Missing values, duplicate records and unsuitable data are handled during the data preparation stage.

📋 Dataset Information

  • Dataset Type: Historical Crime Dataset
  • Geographic Area: Chicago, Illinois
  • Data Domain: Criminal / Crime Data
  • Prediction Target: Community Area
  • Machine Learning Model: Random Forest
  • Application: Crime Area Prediction
