How It Works

Criminal Data Analysis and Crime Area Prediction Using Machine Learning

How the System Works

This project analyzes historical crime data and uses Machine Learning to predict the community area associated with a given crime-related input.

The system takes information such as date, time, police district, beat, ward, geographical coordinates and location description as input. The trained machine learning model processes these features and predicts the corresponding community area.

Project Workflow

1. Data Collection

Historical crime records are collected from the Chicago crime dataset. The dataset contains information about crime type, date, location, district, ward and geographical coordinates.

2. Data Cleaning

Missing values, duplicate records and inconsistent data are handled during the preprocessing stage. The data is prepared for further analysis.

3. Exploratory Data Analysis

Crime patterns are analyzed using different charts and visualizations such as yearly, monthly, hourly and location-based crime trends.

4. Feature Engineering

Useful features are created from the original data, including day of week, weekend indicator, time period and season.

5. Model Training

A Random Forest machine learning model is trained using selected crime-related features to learn patterns associated with community areas.

6. Prediction

The user enters crime-related information through the web form. The trained model processes the information and predicts a community area.

Machine Learning Model

The project uses the Random Forest algorithm for community area prediction. Random Forest combines multiple decision trees and uses their combined predictions to produce the final result.

The trained model is saved as a .pkl file and loaded by the Flask application when the system starts.

Role of Flask

Flask is used as the backend framework of the project. It connects the HTML interface with the Python machine learning model.

When the user submits the prediction form, Flask receives the input values, prepares the data and sends it to the trained Random Forest model. The prediction is then displayed on the web page.
