About This Project

This project was developed to analyze historical crime data and use machine learning to predict the likely community area of a crime.

The system uses a trained Random Forest model and a Flask web application to provide an interactive prediction interface.

  • 📊 Historical crime data analysis
  • 🔍 Data cleaning and exploration
  • ⚙️ Feature engineering
  • 🤖 Random Forest machine learning
  • 🎯 Community area prediction
  • 🌐 Flask web application
