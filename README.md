\# Criminal Data Analysis and Community Area Prediction



\## 📌 Project Overview



\*\*Criminal Data Analysis and Community Area Prediction\*\* is a machine learning project developed to analyze crime data and predict the \*\*Community Area\*\* associated with a crime record based on different crime-related, geographical, and temporal features.



The project uses \*\*Python, Pandas, Scikit-learn, Random Forest, Joblib, and Flask\*\* to build an end-to-end machine learning application.



The trained machine learning model is integrated into a Flask web application where users can enter crime-related information and receive a predicted Community Area.



\---



\## 🎯 Objectives



\* Analyze historical crime data.

\* Perform data cleaning and preprocessing.

\* Explore crime patterns based on time, location, and other features.

\* Engineer useful features for machine learning.

\* Train and evaluate machine learning models.

\* Improve the Random Forest model through tuning.

\* Predict the Community Area for new crime-related inputs.

\* Provide a simple web interface using Flask.

\## 📈 Model Performance



The final tuned Random Forest model achieved:



\*\*Overall Test Accuracy: 91.24%\*\*



The model was evaluated on a held-out test dataset.



> Note: 91.24% is the overall accuracy. Performance differs between individual Community Areas, so the overall accuracy should not be interpreted as the accuracy for every individual class.



\### Model Configuration



```python

RandomForestClassifier(

&#x20;   n\_estimators=100,

&#x20;   max\_depth=20,

&#x20;   min\_samples\_leaf=2,

&#x20;   random\_state=42,

&#x20;   n\_jobs=2

)

```



The trained model is saved as:



```text

models/area\_random\_forest\_tuned.pkl

```

\## ⚠️ Limitations



\* Model performance varies between individual Community Areas.

\* Some Community Areas have substantially lower recall than others.

\* Predictions are based on patterns learned from historical data.

\* A machine learning prediction should not be treated as a guarantee of where a future crime will occur.

\* Changes in crime patterns over time may affect model performance.
